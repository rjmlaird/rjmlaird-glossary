---
term: "Object-based image analysis (OBIA)"
category: earth-observation
aliases: ["OBIA", "GEOBIA"]
short: "Object-based image analysis groups neighbouring pixels into objects, then classifies the objects using shape, texture and context as well as colour."
related: ["pixel-based-classification", "supervised-classification"]
updated: 2026-10-24
---

It suits high-resolution imagery, where one real feature, such as a roof, covers many pixels. It usually gives cleaner maps than classifying each pixel alone.
