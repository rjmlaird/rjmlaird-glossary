---
term: "Infrastructure as code (IaC)"
category: web-architecture
aliases: ["IaC"]
short: "Infrastructure as code is managing servers, networks and other infrastructure through versioned, machine-readable definition files instead of manual configuration."
related: ["version-control", "continuous-deployment"]
updated: 2026-10-24
---

Tools such as Terraform and CloudFormation apply the definitions repeatably. Changes can be reviewed, tested and rolled back like code.
