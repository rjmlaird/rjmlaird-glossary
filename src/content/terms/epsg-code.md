term: "EPSG code"
category: earth-observation
aliases: ["EPSG"]
short: "An EPSG code is a numeric identifier for a coordinate reference system in the EPSG geodetic registry."
related: ["coordinate-reference-system", "wgs-84", "british-national-grid"]
updated: 2026-10-24
---

For example EPSG:4326 is WGS 84 longitude and latitude, and EPSG:27700 is the British National Grid. Quoting the code removes ambiguity about which system is meant.
